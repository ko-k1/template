## Optional Agent Setup

No AI instruction files are generated by default. When project policy permits:

```sh
python3 init-agents.py init --policy allowed
python3 init-agents.py init --policy allowed --tool codex --skills
python3 init-agents.py check
```

For restricted use, explicitly allow each capability (for example,
`--policy restricted --allow instructions`). `prohibited` blocks generation.
This is a generation safeguard, not an enforcement boundary for agent tools.
